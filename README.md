# AIFood – AI Meal Planner Landing Page

A responsive landing page created while following Jonas Schmedtmann’s **Build Responsive Real-World Websites with HTML and CSS** course on Udemy.

I adapted the course project into an AI meal-planning concept, changing the content and presentation around a service that generates personalised meal plans. The project is frontend-only and does not implement any AI functionality.

The landing page can be viewed on this link - https://aw4is.github.io/MealPlanAi-Concept/


## What I Built

- Modern responsive landing page using HTML and CSS
- Sections for features, recipes, reviews, pricing and signup
- Responsive layouts for different screen sizes
- Reusable styling and layout patterns

## What I Learned

The project helped me build a stronger foundation in HTML and CSS, including responsive design, media queries, layout techniques and organising styles for a complete webpage.

## Outcome

The result is a clean, modern landing-page concept that could be adapted for a real product or service.
